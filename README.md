# My First Project - Weather App

Personal project in development: a simple weather application.

## Features

- Displays current temperature, humidity, wind speed, and weather condition.
- Shows the current day and time.
- Allows users to search for any city to get the weather.
- Forecast section for the next 5 days (static display).

## Technologies Used

- JavaScript (with Axios for API requests)
- HTML
- CSS
